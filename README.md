# Crypto Tracker

This project is a Python-based cryptocurrency price tracker.
It uses Selenium to scrape live crypto prices from CoinMarketCap
and saves the data into a CSV file.

## Technologies Used
- Python
- Selenium
- Pandas
- WebDriver Manager

## How to Run
1. Install Python
2. Install required libraries:
   pip install selenium pandas webdriver-manager
3. Run the Python file:
   python crypto.py

## Output
- crypto_prices.csv (contains scraped crypto price data)
